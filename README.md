# VeriSight — AI-Generated Image Detection & Explainability

VeriSight is a deep learning computer vision system that classifies images as **AI-Generated** or **Real** using a ResNet18 transfer learning model.

The system also uses **Grad-CAM** to provide visual explanations of the regions that influenced the model's prediction.

## Project Overview

AI-generated images are becoming increasingly realistic, making it difficult to distinguish synthetic images from real photographs.

VeriSight explores how deep learning can be used to classify images based on visual patterns learned from the CIFAKE dataset.

## Model

- Architecture: ResNet18
- Framework: PyTorch
- Learning approach: Transfer Learning
- Input size: 224 × 224
- Classes: AI-Generated and Real

The ResNet18 model was initialized using ImageNet pretrained weights and adapted for binary image classification.

## Dataset

The project uses the CIFAKE Real and AI-Generated Synthetic Images dataset.

| Split | Images |
|---|---:|
| Training | 90,000 |
| Validation | 10,000 |
| Testing | 20,000 |
| **Total** | **120,000** |

The dataset contains balanced real and AI-generated classes.

## Training

- Optimizer: Adam
- Learning rate: 0.0001
- Loss function: Cross-Entropy Loss
- Batch size: 32
- Image size: 224 × 224

Training augmentation included random cropping, horizontal flipping, and small random rotations.

## Explainability

VeriSight uses **Grad-CAM (Gradient-weighted Class Activation Mapping)** to visualize image regions that contributed to the model's prediction.

This provides an interpretable visual explanation instead of displaying only a classification label.

## Web Interface

The project includes a Gradio interface where users can:

1. Upload an image
2. Analyze the image
3. View the predicted class
4. View the model confidence
5. View the Grad-CAM explanation

## Limitations

VeriSight should not be interpreted as a universal detector capable of identifying every AI-generated image.

The model was trained and evaluated on the CIFAKE dataset, so its performance may differ on images from other distributions, generators, cameras, resolutions, or editing pipelines.

A high confidence score also does not guarantee that a prediction is correct.

Real-world testing is therefore important for evaluating the model's generalization ability.
